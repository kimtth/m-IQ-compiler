# Software Industry

> [!abstract] Reference navigation
> The software industry creates and operates digital products that help people and organizations perform tasks.

## Connected concepts

- [[Topics/process-automation|Process automation]]
- [[Topics/software-as-a-service|Software as a service]]

---

Software consists of instructions and data that run on computing devices. Vendors build software for individual users, organizations, developers, and hardware systems.

## Industry characteristics

- Software can be distributed digitally and updated after release.
- Products may be installed on customer devices or delivered as cloud services.
- Development requires continuing investment in design, engineering, security, and support.
- Products become more valuable when they are reliable, usable, and compatible with customer workflows.

## Common categories

- **Applications:** help users complete tasks.
- **Enterprise software:** supports organization-wide processes.
- **Development tools:** help teams create and operate software.
- **System software:** manages devices and supports applications.

## Typical product workflow

1. Identify a user need and define expected outcomes.
2. Design the product and its technical approach.
3. Build and test a small, useful change.
4. Release it safely and monitor results.
5. Use feedback to improve the product.

## Commercial models

- **Subscription:** recurring payment for continued access.
- **Usage based:** payment linked to consumption.
- **Perpetual license:** a one-time right to use a version of the product.
- **Open source:** source code is available under a license, while revenue may come from hosting, support, or related services.

## Basic measures

- Active and retained users.
- Recurring or usage-based revenue.
- Reliability, performance, and security outcomes.
- Delivery speed and product quality.
- Customer support and satisfaction.

## Key risks

- Security and privacy failures can harm users and organizations.
- Poor reliability or usability can reduce adoption and retention.
- Technical debt can make future changes slower and riskier.
- Dependence on platforms or suppliers can create operational constraints.

## Terminology

- **Application:** software designed for a user task.
- **API:** a defined way for software systems to communicate.
- **Cloud service:** software or infrastructure operated by a provider and accessed over a network.
- **SaaS:** software delivered as an ongoing online service.
- **DevOps:** practices that connect software development with deployment and operation.
