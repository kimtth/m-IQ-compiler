# Prioritised feature backlog

Every row describes a product capability, its implementation note and its
status.

- **Done** — implemented and exercised by the running application.
- **Done (beta)** — the surface is demo-scoped: stub persistence, or no runtime
  behind it. [`08-product-ready.md`](08-product-ready.md) names what is missing
  in each case.
- **Partial** — the mechanism exists; a named part of it does not.
